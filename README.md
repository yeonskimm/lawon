# 법ON · 근로감독 법령·적용기준

근로감독관이 점검·감독 현장에서 휴대폰으로 쓰는 법령 검색·적용기준 확인 웹앱입니다.
현장에서 쓰는 말로 검색하면 **해당 조문과 위반 시 벌칙·과태료 조항**을 한 화면에서 보고,
**상시근로자 수·업종·공사금액**을 넣으면 사업장에 적용되는 의무를 구분해 보여줍니다.

- 실행: **https://yeonskimm.github.io/lawon/**
- 설치 없이 모바일 브라우저에서 바로 사용하며, 홈 화면에 앱으로 추가할 수 있습니다(PWA).

---

## 1. 만든 이유

| 현장의 어려움 | 법ON의 방식 |
|---|---|
| 점검표에 없는 위반은 별지로 적어야 해서 폭넓은 법조 확인이 필요함 | 수록 법령 전체를 한 번에 검색 |
| 국가법령정보센터는 조문 → 벌칙 → 시행령 별표(과태료)를 하나씩 찾아가야 함 | 조문 아래에 벌칙·과태료 근거 조항과 금액을 바로 표시 |
| 현장 용어와 법령 용어가 다름(그라인더, 고임목, 주휴 등) | 현장 용어를 법령 용어로 바꿔 검색 |
| 규모(5명·30명·50명 등)·업종·공사금액에 따라 적용 조항이 달라짐 | 조건을 넣으면 적용·비적용·확인 필요로 구분 |

## 2. 주요 기능

**법령 검색**
- 현장 용어 검색: `그라인더 → 연삭숫돌`, `고임목 → 구름멈춤대·쐐기`, `주휴 → 휴일(근로기준법 제55조)`
- 분야 우선 검색: 근로기준 분야에서는 근로기준 법령, 산업안전 분야에서는 산업안전 법령 조문을 먼저 보여 주고, 다른 분야 조문은 그 아래 따로 표시
- 여러 단어 동시 검색: 쉼표·띄어쓰기로 구분하면 모두 포함한 조문만 표시 (예: `지게차, 헤드가드`)
- 조사가 들어간 원문도 검색: `출입금지`로 찾으면 '출입의 금지'로 쓰인 안전보건규칙 제20조도 표시
- 제재 조건 검색: `작업환경측정 과태료`처럼 '과태료'·'벌칙'을 붙이면 그 제재가 붙은 조문만 표시
- 조문 번호 바로 찾기: `산안법 125조`처럼 법령 이름과 조 번호를 넣으면 해당 조문만 표시
- 조문을 먼저 보여주고, 이어서 벌칙·과태료 근거 조항과 과태료 금액 표시
- 법 → 시행령 → 시행규칙 연결: 법 조문 화면에 위임받은 시행령·시행규칙 조문을, 시행령·시행규칙 조문 화면에 근거 법 조문과 그 벌칙·과태료를 함께 표시. 검색 결과에서도 하위 조문을 법 조문 아래로 묶음
- 공포 후 시행 전인 개정 조문은 별도 표시하고, 시행일이 지나면 개정 후 조문·제재로 자동 전환(개정 전 조문·제재는 시행일 전 위반행위 확인용으로 조문 아래 수록)
- 현장 표현 검색: `안전교육 미실시`, `퇴직금 미지급`처럼 '미실시·미지급·미선임'을 붙여도 해당 조문 표시
- 조문이 가리키는 별표를 조문 화면에 연결하고, 앱에 수록하지 않은 별표는 국가법령정보센터 원문 링크로 안내

**적용 확인**
- 근로기준 분야: 상시근로자 수로 5명 미만 적용 제외 조항 등 구분
- 산업안전 분야: 업종·상시근로자 수·건설공사 금액으로 안전보건관리책임자, 안전·보건관리자, 산업안전보건위원회 등 선임·설치 의무 판정
- 입력이 부족하면 단정하지 않고 '확인 필요'로 표시

**법령집·별표**
- 법령별 목차 탐색
- 특별교육 대상 작업별 교육내용, 특수건강진단 대상 유해인자, 해고예고 예외 귀책사유, 안전·보건관리자 선임 기준과 자격, 휴게시설 설치·관리기준, 교육시간 등 현장에서 자주 찾는 별표 수록

**상시근로자 수 계산기**
- 근로기준법 시행령 제7조의2에 따른 산정을 돕는 별도 도구(조회 조건과 연동하지 않음)

## 3. 수록 범위

2026. 9. 24. 기준. 법령별 반영 공포번호는 앱의 법령집 화면과 `tools/law_versions.json`에서 확인할 수 있습니다.

| 분야 | 법령(조문) | 별표 |
|---|---|---|
| 근로기준 | 근로기준법, 최저임금법, 근로자퇴직급여 보장법, 남녀고용평등과 일ㆍ가정 양립 지원에 관한 법률, 기간제 및 단시간근로자 보호 등에 관한 법률, 파견근로자 보호 등에 관한 법률, 노동조합 및 노동관계조정법(이상 시행령·시행규칙 포함), 근로자참여 및 협력증진에 관한 법률(시행령 포함) | 근로기준법 시행령·시행규칙, 최저임금법 시행규칙, 기간제법 시행령, 파견법 시행령·시행규칙, 고평법 시행규칙, 노조법 시행령 |
| 산업안전 | 산업안전보건법(시행령·시행규칙 포함), 산업안전보건기준에 관한 규칙, 유해ㆍ위험작업의 취업 제한에 관한 규칙, 중대재해 처벌 등에 관한 법률 및 시행령 | 산업안전보건법 시행령·시행규칙, 산업안전보건기준에 관한 규칙, 취업제한규칙, 중처법 시행령 |
| 감독 업무 | 근로감독관집무규정, 근로감독관 집무규정(산업안전보건), 노동감독관 직무집행법(2026. 12. 8. 시행) | 집무규정 2종(위반사항 조치기준 등) |

- 조문 2,398개(시행령·시행규칙 815개 포함), 별표 87개, 현장 검색어 205개
- 과태료 부과금액(1~3차): 근로기준법·최저임금법·근로자퇴직급여 보장법·고평법·기간제법·파견법·근참법·노조법·산업안전보건법·중처법 시행령의 과태료 부과기준 별표 반영
- 과태료 부과기준 별표는 일반기준(가중·감경 등)만 별표 화면으로 수록하고, 위반행위별 금액은 각 위반 조문에 표시. 별표 전체는 국가법령정보센터 원문 링크로 연결

## 4. 정확성 관리

법령 앱은 틀린 답을 내면 안 되므로, 아래 장치를 두었습니다.

**배포 전 자동 검사** — GitHub에 올리면 검사를 먼저 돌리고, 하나라도 실패하면 배포하지 않고 기존 화면을 유지합니다(`.github/workflows/deploy.yml`).

| 검사 | 내용 |
|---|---|
| `tests/judge_boundary.js` | 기준 인원·공사금액 바로 아래와 기준값에서 판정이 바뀌는지 (4→5명, 49→50명, 건설 19→20억 등). 기대값은 코드가 아닌 **법령 원문 기준**으로 작성 |
| `tests/judge_headcount.js` | 업종·규모별 안전관리자·보건관리자 선임 인원 |
| `tests/search_regression.js` | 현장 검색어가 기대한 조문을 찾는지 |
| `tests/field_priority.js` | 선택한 분야 법령이 먼저 나오고, 다른 분야 결과도 빠지지 않는지 |
| `tests/sublaw_check.js` | 시행령·시행규칙 조문 수가 원문과 같은지, 법 조문 연결이 실제 조문을 가리키는지 |
| `tests/and_search_test.js` | 여러 단어를 쉼표·띄어쓰기로 넣으면 모두 포함한 조문만 나오는지 |
| `tests/search_lawname_test.js` | 법령 이름·조문 번호 검색(`산안법 125조` 등)과 별표 연결이 맞는지 |
| `tests/due_test.js` | 공포 후 시행 전 개정이 시행일에 개정 후 조문·제재로 바뀌고 개정 전 내용이 남는지(근기법 2026. 10. 8. 체불 벌칙 이동 등), 위험성평가 과태료 금액 |
| `tests/check_sw_scope.js` | 앱 업데이트 시 같은 주소의 다른 앱 저장본을 지우지 않는지 |

**법령 개정 주간 점검** — 매주 월요일 공공데이터포털 '법제처 국가법령정보 공유서비스'로 수록 법령의 공포번호를 조회해 앱 반영본과 비교하고, 달라지면 이 저장소에 이슈로 알립니다(`.github/workflows/law-check.yml`, `tools/check_laws.py`). 점검은 발견만 하고, 앱 데이터 반영은 원문을 확인한 뒤 사람이 합니다.
- 공포번호가 맞으면 법제처 현행 공포번호·시행일을 `tools/law_meta.json`에 저장하고, 배포할 때 법령집 화면에 넣습니다(`tools/inject_meta.py`).
- 시행 전인 제정 법령(노동감독관 직무집행법)은 시행일부터 대조합니다. 훈령인 집무규정 2종은 이 점검 대상이 아니어서 개정 여부를 따로 확인합니다.

## 5. 사용 방법

| 기기 | 홈 화면에 설치 |
|---|---|
| 안드로이드 | Chrome에서 열기 → 앱 안의 '홈 화면에 앱 설치' 또는 메뉴 → 홈 화면에 추가 |
| 아이폰 | Safari에서 열기 → 공유 버튼 → 홈 화면에 추가 |

- 새 버전을 올리면 설치된 앱이 자동으로 갱신됩니다.
- 한 번 열면 인터넷 연결이 약한 현장에서도 사용할 수 있습니다.
- 사업장명·사진 등 식별정보를 입력받지 않으며, 입력 내용을 서버로 보내지 않습니다.

## 6. 구성

서버 없이 동작하는 단일 HTML 웹앱입니다. 법령 데이터는 `index.html` 안에 들어 있습니다.

```
index.html            앱 화면·검색·판정 로직과 법령 데이터
manifest.json         홈 화면 앱 설정
service-worker.js     오프라인 사용·자동 업데이트
icon-192.png, icon-512.png, icon-maskable-512.png   홈 화면 아이콘
tests/                배포 전 자동 검사(.js) · 화면 검사(.py, 수동 실행)
tools/                법령 개정 점검(check_laws.py, law_versions.json), 법령집 표기(law_meta.json, inject_meta.py)
.github/workflows/    배포(deploy.yml)·개정 점검(law-check.yml)
```

## 7. 개발 방식

- 감독관이 요구사항 정의, 법령 원문 수집, 현장 용어 선정, 실제 기기 확인을 맡고, 생성형 AI(Claude)를 활용해 법령 원문 가공·대조, 앱 코드, 자동 검사를 작성했습니다.
- 앱 자체는 AI가 답을 생성하지 않고 **법령 원문 데이터와 판정 규칙**으로만 결과를 보여줍니다. 그래서 같은 입력에는 항상 같은 결과가 나오고, 검사로 결과를 확인할 수 있습니다.

## 8. 유의사항

국가법령정보센터에서 위반행위 당시 시행 법령을 확인하시기 바랍니다.

## 5. 이용자 수 집계

- 하루 한 번 기기에서 만든 무작위 번호만 Cloudflare Worker로 보내 이용자 수를 셉니다. 검색어·입력한 조건은 보내지 않습니다(앱 설정 화면에 고지).
- 집계 서버 코드는 `tools/lawon-stats-worker.js`(Cloudflare Workers + D1). 배포 주소(yeonskimm.github.io)에서 연 경우에만 보냅니다.
- 관리자 모드: 첫 화면의 책자·앱 이름을 3초 안에 5번 누르면 비밀번호를 받아 날짜별 이용자(최근 30일)·신규·누적을 보여줍니다.
